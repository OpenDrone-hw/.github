# Security policy

Report security issues privately. Do not open a public issue, pull request or
discussion for a vulnerability.

| What | Where |
| --- | --- |
| Report a vulnerability | Email security@opendrone.be |
| Policy | https://opendrone.be/security |
| Machine-readable contact | https://opendrone.be/.well-known/security.txt |
| Languages | English, Dutch, French |

Include the affected repository, board or firmware, the version or commit, the
steps to reproduce and the impact you observed. This policy covers every
repository in the OpenDrone-hw organization. Forks of upstream projects (AM32,
Betaflight, ExpressLRS) also follow the upstream project's own policy for
issues that are not specific to OpenDrone changes.
